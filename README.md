# SatPass Planner

Public part of SatPass Planner, an app for iPhone, iPad and Mac that predicts satellite passes on your device. It has a multi-satellite timeline, Doppler tuning, and radio and rotator control through Hamlib.

- [Support](SUPPORT.md): help, bug reports and feature requests
- [Privacy Policy](PRIVACY.md): SatPass collects no data

Questions and bug reports: [open an issue](https://github.com/Tuareg0xFFFF/SatPass-PUB-/issues).
