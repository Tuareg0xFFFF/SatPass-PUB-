# SatPass Planner

This repository is the public part of SatPass Planner. SatPass Planner is an app for iPhone, iPad and Mac that predicts satellite passes on your device. It has a timeline for many satellites, Doppler tuning, and radio and rotator control through Hamlib.

- [Support](SUPPORT.md): help, problem reports and feature requests
- [Privacy Policy](PRIVACY.md): SatPass collects no data

For questions and problem reports, [open an issue](https://github.com/Tuareg0xFFFF/SatPass-PUB-/issues).
